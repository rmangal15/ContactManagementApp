# Contact Management App

## Description
A simple Contact Management Application developed using Java. It allows users to manage their contacts through a menu-driven interface.

## Features
- Add a new contact
- View all contacts
- Search contacts by name or phone number
- Update existing contact details
- Delete contacts
- Save contact data in a file

## Technologies Used
- Java
- File Handling
- Object-Oriented Programming

## How to Run
1. Open the project folder in VS Code.
2. Compile the Java files.
3. Run the Main class.
4. Follow the menu options displayed in the terminal.

## Project Files
- Main.java — Main program
- Contact.class — Compiled Contact class
- Main.class — Compiled Main class
- Contacts.dat — Contact data storage file
